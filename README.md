# Java Beginner Problem Solving

This repository contains beginner-level Java programming problems that are commonly asked in coding interviews and placement tests. These programs help build problem-solving skills and strengthen Java fundamentals.

## Problems Covered

1. Even or Odd
2. Positive, Negative, or Zero
3. Largest of Two Numbers
4. Largest of Three Numbers
5. Swap Two Numbers
6. Factorial of a Number
7. Multiplication Table
8. Sum of First N Natural Numbers
9. Reverse a Number
10. Prime Number Check
11. Palindrome Number Check

## Concepts Used

- Variables and Data Types
- Scanner Class
- Operators
- Conditional Statements (if-else)
- Loops (for, while)
- Basic Logic Building

## Tools

- Java
- VS Code
- Git & GitHub

## Goal

Practice Java fundamentals and prepare for coding interviews and placement exams.
